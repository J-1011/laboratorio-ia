# Caratteri del sito

Il sito usa gli stessi caratteri delle slide. Funziona anche senza: se questi
file mancano, il browser usa i caratteri già presenti sul computer.

## Quali file servono

Copiare in questa cartella questi quattro file, con questi nomi esatti:

| File | Si scarica da | Dove si trova nello ZIP |
|---|---|---|
| `Rubik-Bold.ttf` | <https://fonts.google.com/specimen/Rubik> | cartella `static` |
| `IBMPlexSans-Regular.ttf` | <https://fonts.google.com/specimen/IBM+Plex+Sans> | cartella `static` |
| `IBMPlexSans-SemiBold.ttf` | <https://fonts.google.com/specimen/IBM+Plex+Sans> | cartella `static` |
| `IBMPlexMono-Medium.ttf` | <https://fonts.google.com/specimen/IBM+Plex+Mono> | cartella principale dello ZIP |

## Come fare

1. Da ognuna delle tre pagine qui sopra, scaricare il file ZIP del carattere.
2. Aprire gli ZIP e copiare qui i quattro file della tabella.
3. Ricaricare la pagina nel browser. Non serve riavviare il sito.

Il download si fa una volta sola, da chi prepara il sito. Le pagine non chiedono
mai niente a Google: i caratteri arrivano da questa cartella, quindi funzionano
anche senza internet.

I tre caratteri hanno la licenza SIL Open Font License, che permette di usarli
e copiarli liberamente.
